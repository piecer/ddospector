# AI 모델 설정 — AI-02

이 화면은 모델을 실행하는 화면이 아니라 **다음 실행 단계에서 사용할 설정 초안**을 관리하는 화면입니다. 설정 저장·기본 프로필 선택·에이전트 연결은 모델 호출이나 운영 승인이 아닙니다.

## 접근

사이드바의 `AI 설정` 또는 기존 `AI 에이전트`/시스템 `설정` 화면의 `AI 설정` 버튼을 사용합니다. 직접 주소는 `/ai-settings`입니다. 화면 언어는 상단의 영어/한국어 선택을 따릅니다.

## 모델 프로필

1. 프로필을 추가하고 이름, 프로토콜, 모델 ID를 입력합니다.
2. 필요하면 Base URL과 API 키 환경변수 **이름**을 지정합니다.
3. 고급 옵션이 필요한 경우에만 펼쳐 조정합니다.
4. 저장 후 목록에서 기본 초안을 선택합니다. 첫 프로필도 자동 선택되지 않습니다.
5. 검토 에이전트에 다른 프로필을 지정할 수 있습니다. 별도 지정이 없으면 기본 초안을 따릅니다.

`Anthropic`, `OpenAI Chat Completions`, `OpenAI Responses`는 공급사 이름 목록이 아니라 **통신 프로토콜 구분**입니다. 호환 서버를 사용하는 경우 그 서버가 제공하는 프로토콜·모델 ID·주소를 입력합니다. 모델 ID는 임의의 제품 별칭으로 바꾸지 않습니다.

예를 들어 로컬 서버를 나중에 연결할 계획이라면 Base URL에 `http://127.0.0.1:1234/v1`을 기록할 수 있습니다. 이것은 예시 주소이며 서버가 설치·실행되어 있거나 해당 모델이 존재한다는 뜻이 아닙니다. 주소 저장만으로 연결하지 않습니다.

프로필은 최대 20개이며 이름은 중복할 수 없습니다. 기본값이나 에이전트에 연결된 프로필을 삭제하려면 먼저 해당 연결을 해제하거나 변경합니다. 삭제에는 별도 확인이 필요합니다.

## 비밀 정보

API 키 입력란은 없습니다. `OPENAI_API_KEY` 같은 환경변수 참조명만 저장합니다. 실제 키를 이름·주소·모델 ID 등 다른 필드에 넣지 마세요. 현재 단계에서는 참조 대상 환경변수의 값이나 존재 여부도 조회하지 않습니다.

사용자 정보가 포함된 URL, 쿼리 문자열, 프래그먼트 및 임의 헤더/프록시 설정은 허용하지 않습니다. 프로필은 서버의 로컬 JSON 저장소에 저장하며 브라우저 localStorage에 저장하지 않습니다. 로컬 개발용 저장소이지 운영용 비밀 저장소나 인증 시스템이 아닙니다.

## 고급 옵션의 의미

- 초당/분당 요청 제한: `0`은 프로필별 제한을 지정하지 않음. 아직 요청 엔진이 없으므로 실제 제한을 적용한 것이 아닙니다.
- 컨텍스트 크기(K): 모델의 전체 문맥 용량에 대한 설정입니다. `0`은 참고 기본값 200K, 명시적 값은 32~1000K입니다. 출력 상한과 다릅니다.
- 출력 토큰 상한: `0`은 이후 요청에서 상한 필드를 생략하도록 의도한 값입니다.
- 출력 상한 필드명: Chat Completions에서만 `max_tokens`(기본) 또는 `max_completion_tokens`를 구분합니다. 다른 프로토콜로 바꾸면 호환되지 않는 필드 선택을 초기화합니다.
- 스트리밍, thinking 유형, reasoning effort는 서로 독립된 설정입니다. 모델이 각 옵션을 지원하는지는 검증하지 않습니다.
- 재시도: connect/empty/stream 계층별 정책 초안입니다. 횟수 `-1`은 비활성, `0`은 상속/기본, 양수는 지정 횟수입니다. 간격 `0`은 기본 전략이며 양수는 밀리초입니다. 실제 재시도나 장애조치는 실행하지 않습니다.

빈 숫자나 잘못된 숫자가 자동으로 `0`으로 바뀌지는 않습니다. 유효한 값을 입력해야 저장할 수 있습니다.

## 저장 충돌과 실패

서버는 설정의 revision을 비교합니다. 다른 창에서 먼저 저장한 경우 오래된 창의 덮어쓰기를 거부합니다. 오류나 시간 초과는 저장되지 않았다는 증거가 아니므로 동일 저장을 자동 반복하지 않습니다.

불확실한 저장이나 충돌 뒤에는 최신 설정을 명시적으로 다시 불러와 확인합니다. 다시 불러오기가 로컬 편집 초안을 버리는 동작이면 화면에서 이를 알립니다. 새로 불러온 revision에 과거 편집 내용을 자동 적용하지 않습니다.

기존 UI-01 데이터는 읽을 때 메모리에서만 형식을 확장하고, 다음 정상적인 초안 변경 때 버전 2로 저장합니다. 손상된 저장 파일을 자동 초기화하지 않으며, 기존 대상·Skill·MCP·캠페인·감사 기록을 보존합니다.

## 실행 제한

연결 테스트·모델 목록 조회는 비활성화되어 있으며 서버에서도 거부합니다. 모든 프로필은 `초안 / 미검증`이며, 정상 상태·지연시간·모델 응답을 만들어 표시하지 않습니다. 실제 추론, MCP 접속, 장비 제어, LIVE 시험은 별도 구현·승인 단계입니다.

정확한 API, 필드 범위, 동시성·마이그레이션 및 수용 조건은 `AI_SETTINGS_CONTRACT.md`를 참조하세요.

이름 비교와 URL 메타데이터 검증은 프로젝트 Python 3.12의 Unicode/IDNA 규칙을 따릅니다. 브라우저 버전에 따라 저장된 설정이 읽히지 않는 일을 막기 위해 고정된 생성 테이블과 생산자 응답 차등 검사를 사용합니다. 개발·검증 환경에는 Python과 웹 의존성이 모두 필요합니다 (`make setup`). 생성 절차와 의미는 `AI_SETTINGS_COMPATIBILITY.md`에 정리되어 있습니다.
