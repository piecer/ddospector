# DDoSpector UI-01 / AI-02 사용 안내

## 이번 구현의 범위

전체 UI 레이아웃과 메뉴를 먼저 확인하는 로컬 워크스페이스입니다. 화면에 입력한 초안은 실제 API를 통해 저장합니다. 단순한 정적 목업이나 샘플 실행 결과 화면이 아닙니다.

다만 현재는 **설정·지침 준비 단계**입니다. AI 모델 추론, MCP 서버 연결, 장비 제어, 트래픽 송신, 운영 승인과 시험 결과 판정은 아직 수행하지 않습니다. UI 버튼뿐 아니라 서버의 실행 API도 실행을 거부합니다.

## 시작하기

프로젝트 경로에서 실행합니다. Node.js 24 계열, npm, uv가 필요하며 프로젝트 Python은 3.12입니다. 시스템 Python을 변경하지 않습니다.

```sh
make setup
```

터미널 두 개에서 각각 실행합니다.

```sh
make api
```

```sh
make web
```

화면 주소: `http://127.0.0.1:5173` (기본 주소에서 개요 화면을 엽니다.)

API 주소: `http://127.0.0.1:5180`

WSL의 localhost 전달이 활성화되어 있으면 Windows 브라우저에서도 같은 주소로 접근할 수 있습니다. 다른 프로그램이 포트를 사용 중이라면 해당 프로세스를 임의로 종료하지 마세요. 이 구성은 로컬 개발용이며 외부 공개나 터널 연결을 위한 인증·권한 체계를 제공하지 않습니다.

우측 상단에서 English/한국어를 선택합니다. 언어 선택은 브라우저에 저장합니다. 사용자가 작성한 이름·메모·지침은 임의로 번역하지 않습니다. `Ctrl+K` 또는 `Cmd+K`로 페이지 검색을 열 수 있습니다. 작은 화면에서는 상단 메뉴 버튼으로 탐색 메뉴를 엽니다.

## 권장 확인 순서

### 1. 시험 대상 등록

시험 대상 화면에서 이름, IP 주소 또는 호스트 이름, 역할을 입력해 초안을 저장합니다. 저장은 대상에 접속하거나 트래픽을 허가하는 작업이 아닙니다.

### 2. MCP 사용 지침 등록

MCP 서버 화면에서 서버 이름과 전송 방식을 선택합니다.

- Streamable HTTP: HTTP(S) 엔드포인트를 입력합니다. 사용자 정보, 쿼리 문자열, 프래그먼트와 자격증명은 포함하지 않습니다.
- Standard I/O: 등록된 서버를 가리킬 ID를 입력합니다. 실행 명령이나 임의 셸 코드를 넣는 칸이 아닙니다.

AI 사용 지침에는 사용 목적, 사전 조건, 허용 범위, 필요한 증거를 적습니다. 저장해도 서버에 연결하거나 도구를 검색하지 않습니다.

### 3. Skill 준비

내장 지침은 정책 검증 계획, MCP 측정 절차, 증거 검토로 구성됩니다. 사용자 Skill은 이름, 버전, 설명, 지침 등을 입력하여 초안으로 추가합니다.

Skill은 작업 절차입니다. 승인이나 안전 한도를 우회하는 권한이 아닙니다. 지침에 비밀번호·API 키·토큰을 넣지 마세요. 별도의 자격증명 저장소는 아직 구현되지 않았습니다.

### 4. 에이전트에 할당

AI 에이전트 화면에서 사용할 Skill과 등록한 MCP 사용 지침을 선택하고 할당을 저장합니다. 아직 저장하지 않은 선택과 저장된 할당은 구분됩니다. 현재 모드는 검토 전용이며, 할당 저장은 운영 승인이 아닙니다.

### 5. 컨텍스트 미리보기

검토 목표를 입력하고 컨텍스트 미리보기를 조합합니다. 저장된 할당과 지침이 어떤 맥락으로 전달될지 확인하는 기능입니다.

이 결과는 **결정적 텍스트 조립**이며 LLM 응답, 실제 추론, 도구 호출 또는 시험 결과가 아닙니다.

### 6. 캠페인 초안 생성

시험 캠페인 화면에서 등록된 대상과 내장 프로파일 템플릿을 선택하여 초안을 저장합니다. 실제 장비 연결이나 LIVE 실행은 시작되지 않습니다. 감사 로그에서 저장·할당 변경 내역을 확인할 수 있습니다.

## 저장과 운영 경계

AI 모델 설정은 `AI_SETTINGS_GUIDE_KO.md`를 참고하세요. 복수 모델 프로필을 관리하며 키 값 대신 환경변수 참조명만 저장합니다. 설정은 미검증 초안이며 연결 테스트·모델 조회·추론을 수행하지 않습니다.

- 기본 저장 위치는 프로젝트의 `.local/ui-drafts.json`입니다. `DDOSPECTOR_UI_STATE_PATH`로 바꿀 수 있습니다. 이전 `AIDDOS_UI_STATE_PATH`도 지원하지만, 두 변수가 모두 있으면 새 변수를 사용합니다. 빈 값도 명시한 값으로 취급하여 이전 설정으로 조용히 되돌리지 않습니다. 이름 전환 범위는 `NAMING.md`를 참고하세요.
- 단일 API 프로세스용 로컬 JSON 저장소입니다. 운영용 PostgreSQL, 다중 프로세스 공유 저장소, 로그인·RBAC를 대체하지 않습니다.
- 기존 초안 컬렉션별 상한은 100개, AI 모델 프로필은 20개이며 최근 감사 기록은 최대 500개를 보관합니다. 감사 화면의 목록을 전체 수명 동안의 이력으로 해석하지 마세요.
- 기존 상태가 손상되면 오류를 알리며 조용히 초기화하지 않습니다. 실험 전 상태 파일을 별도로 백업하세요.
- 시험 대상·MCP 초안 저장은 성공했지만 목록 재조회가 실패했다면 대화상자의 새로고침 재시도 또는 닫기를 사용합니다. 재시도는 저장을 반복하지 않습니다. 오래된 목록을 표시하는 동안 새 변경은 막고, 조회 복구 후 다시 허용합니다.
- AI 모델 프로필은 편집·삭제를 지원합니다. 기존 시험 대상·MCP·Skill·캠페인은 초안 생성과 할당 중심이며 전체 편집·삭제 수명주기는 후속 범위입니다.
- 준비 진행률, 구성도, 등록 개수는 실행 가능 여부나 장비의 실제 온라인 상태를 의미하지 않습니다.

## 검증 명령

```sh
make test
make lint
make build
make test-e2e
```

Chromium이 설치되지 않았다면 먼저 `web` 디렉터리에서 `npx playwright install chromium`을 실행합니다.

브라우저 검증은 별도 포트와 고유 상태 파일을 사용합니다. 개발 워크스페이스를 테스트 데이터로 채우지 않습니다. 결과·화면 캡처는 `.hermes/artifacts/ui-01/`에 보관합니다. 실제 장비, 실제 모델/MCP 제어, 물리 기기와 사람이 사용하는 스크린리더 검증은 이 단계의 자동 테스트와 구별됩니다.
